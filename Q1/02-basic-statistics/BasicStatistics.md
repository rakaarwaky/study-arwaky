# Basic Statistics — Field Doc

> One specific sub-field. ~26 h over the quarter (4 sessions x 2 h).
> **Unlocks:** Data Analysis in Python + Machine Learning (Q2).
> **No context switching:** this field only on your assigned day.
> Structure = **roadmap.sh Basic Statistics**, 10 sections.

## Why this slice
Descriptive statistics, probability, and inference are the tools that let you read
and trust data. Without them, any data-driven decision is a guess.

## Resources
- **Khan Academy — Statistics & Probability** (main track).
- **3Blue1Brown — *Statistics*** (intuition layer).
- **Khan Academy — "How to interpret a p-value"** (inference).
- **roadmap.sh Basic Statistics** (full tree is `roadmap-sh-basic-statistics.md`).

## 2-hour daily template
- 0:00-0:05 — State goal: "By end I can explain X."

- 1:00-1:50 — Compute real numbers: given a dataset, find mean/SD/z; solve 3-4 problems.

## Exit test
Given a table of numbers, hand-compute mean and SD, state what the SD tells you,
explain the difference between correlation and causation in 2 sentences, and build
one confidence interval.
