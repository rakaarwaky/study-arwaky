# F2 — Basic Statistics — Field Doc

> One specific sub-field. ~26 h over the quarter (4 sessions × 2 h).
> **Unlocks:** Data Analysis in Python + Machine Learning (Q2).
> **No context switching:** this field only on your assigned day.

## Why this slice
Descriptive stats + distributions + a taste of inference that let you read and trust data.

## Resources
**Khan Academy — Statistics & Probability** (main track).
**3Blue1Brown — *Statistics*** (intuition layer).
**Khan Academy — 'How to interpret a p-value'** for inference.

## 2-hour daily template
- 0:00–0:05 — State goal: "By end I can explain X."
- 0:05–1:00 — Input: 1–2 focused videos + read (this field only).
- 1:00–1:50 — Compute real numbers: given a dataset, find mean/SD/z; solve 3–4 problems.
- 1:50–2:00 — Write 2–3 sentences (in English) on what I learned + 1 gap.
